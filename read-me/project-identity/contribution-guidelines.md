# Protocol-7 Contribution Guidelines

## Getting Started

### Initial Steps
0. Familiarize yourself with the codebase structure
1. **Contact Taeki**: Discuss potential contributions before beginning work

## Contribution Process

### Communication
- Reach out directly to Taeki ( p7-src@taeki.v7.ax ) to discuss:
  - Proposed changes
  - Project alignment
  - Potential implementation approaches

### Philosophical Alignment
Contributions should resonate with the project's core principles:
- Harmonic computing
- Transparent, human-readable protocols
- Distributed resource sharing
- Mathematical justice frameworks

## Contribution Types
- Code improvements
- Documentation enhancements
- Philosophical research
- Zenki (agent) development
- Infrastructure optimization
