# .env.session Variable Reference

This file documents the variables in `.env.session` (pure KEY=VALUE format, no comments).

## Repository Configuration
```
PROTOCOL7_ROOT          - Root path to Protocol-7 repository
PROTOCOL7_BRANCH        - Current working branch
PROTOCOL7_ZENKA         - Active zenka name
GIT_REPOSITORY_PATH     - Path for git operations
```

## Session Context
```
SESSION_TYPE            - Type of development session
SESSION_DATE            - Session date (YYYY-MM-DD)
SESSION_STATUS          - Overall status (all_committed_and_pushed, etc.)
SESSION_COMMITS_TOTAL   - Number of commits in session
SESSION_FILES_CREATED   - Files created this session
SESSION_FILES_MODIFIED  - Files modified this session
```

## Documentation Files
```
SESSION_SUMMARY_FILE    - Detailed session accomplishments
SESSION_PATTERNS_FILE   - Protocol-7 patterns learned
SESSION_STARTUP_FILE    - Complete startup guide
SESSION_QUICK_START_FILE - Quick start markdown
```


## Usage Examples

**Grep for tasks:**
```bash
grep "^TASK_P1" .env.session
```

**Get recent work:**
```bash
grep "^SESSION_WORK" .env.session
```

**Find module paths:**
```bash
grep "^MODULE_" .env.session
```

**Check what needs implementation:**
```bash
grep "^NEEDS_IMPL" .env.session
```

**Get quick start:**
```bash
grep "^QUICK_START_COMMAND" .env.session | cut -d= -f2-
```
