================================================================================
  SECURITY MODEL
================================================================================

TOKEN MANAGEMENT:
  Storage:   Environment variable → Config file → Prompt
  Encoding:  Plain text (intentional for git operations)
  Transport: HTTPS with curl/git (no plaintext network)
  Security:  File permissions 0600, ENV var in memory only
  Rotation:  New token can be saved anytime

GIT REMOTE CONFIGURATION:
  Method:    HTTPS with embedded token
  Advantage: Works in container without SSH
  Security:  Token invalidated via GitHub UI anytime

CONFIGURATION FILES:
  Storage:   JSON format in /home/.config/
  Default:   World-readable (contains no secrets)
  Token:     Owner-readable only (0600 permissions)

================================================================================
  DISASTER RECOVERY
================================================================================

IF REPOSITORIES CORRUPTED:
  rm -rf /home/workspace-transfer /home/protocol-7
  perl /home/ENVIRONMENT-BOOTSTRAP.pl
  → Repositories re-cloned, configuration preserved

IF DEPENDENCIES LOST:
  perl /home/ENVIRONMENT-BOOTSTRAP.pl
  → All modules reinstalled, no configuration loss

IF CONFIGURATION INVALID:
  rm /home/.config/bootstrap.json
  perl /home/ENVIRONMENT-BOOTSTRAP.pl
  → Configuration regenerated with current environment

IF TOKEN COMPROMISED:
  1. Invalidate on GitHub
  2. echo "ghp_new_token" > /home/.config/github.token
  3. chmod 600 /home/.config/github.token
  → New token immediately active, old token revoked
