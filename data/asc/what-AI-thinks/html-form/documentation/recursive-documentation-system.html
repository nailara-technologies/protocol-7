I. Knowledge Node Structure

Q1: How should the three-paragraph metadata system be precisely structured?

Each document node should contain three introductory paragraphs: one describing what the second paragraph describes, one describing what is not covered, and one containing the essence of the information.

These paragraphs function as meta-cognitive primers to help both humans and LLMs better contextualize the information and avoid overgeneralization.

sub generate_new_knowledge_node {
    my ($technical_details, $style_template, $research_question) = @_;

    # Formulate the LLM prompt
    my $prompt = construct_node_generation_prompt(
        $technical_details,
        $style_template,
        $research_question
    );

    # Request document from LLM
    my $raw_node_content = query_llm($prompt);

    # Extract the three-paragraph structure
    my $structured_node = extract_paragraph_structure($raw_node_content);

    # Generate node checksum

    # Determine node placement in hierarchy
    my $parent_path = determine_parent_node($structured_node, $knowledge_tree);

    # Construct full node path
    my $node_path = $parent_path ? "$parent_path.$checksum" : $checksum;

    # Store the node
    store_knowledge_node($node_path, $structured_node);

    return $node_path;
}
