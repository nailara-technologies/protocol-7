## Usage Examples

### Initialize Living Tree
```perl
use lib './lib';
require './living_tree_bootstrap.pl';

my $tree = LivendTree->bootstrap({
    root => '/path/to/tree',
    harmonic_mode => 'base32',
});
```

### Extract from Archive
```perl
use lib './lib';
require './living_tree_extractor.pl';

my $extracted = extract_living_tree(
    archive => 'tree.self-extracting.pl',
    destination => '/target/path'
);
```
