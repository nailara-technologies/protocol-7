## what the iris gains from this mapping

### live layer depth display

each module node in the iris already has a ring position (BMW384 coordinate).
the layer stack adds a second axis: **how deeply refined is this module's reasoning?**

```
current:   ring position = namespace depth (structural)
new:       ring brightness = reasoning layer depth (dynamic)
           dim ring glow  = layer 0 (raw, unrefined)
           mid ring glow  = layers 2-4 (structured, active)
           bright glow    = layer 5-6 (holographic, seed-level)
           peak glow      = layer 7 / threshold reached
```

the iris becomes a live map of the reasoning system's current refinement state.
you can see at a glance which namespaces are being actively reasoned about
and how deeply they have been refined.

### the CCW spin made visible

the iris currently shows rings as static.
the vortex connection makes CCW rotation the natural animation:

```
gentle CCW rotation of all rings:
  rotation speed ∝ convergence activity (faster when threshold crossings happening)
  each threshold crossing event: brief pulse of brightness at that ring position
  the pulse follows the CCW direction — you can see the reasoning "flow"
  from outer rings (layer 0) inward toward center (EXISTENCE)

galactic arms visible as:
  bright arcs connecting ring positions where active reasoning paths exist
  arcs curve CCW (following the spin direction)
  arc intensity = approach vector strength toward the target node
  multiple arcs converging on same ring position = deduplication happening
```

### color as entropy accounting

template 9 (vortex): all color accounted for, proportion always precise.
the iris already uses color by namespace. the mapping makes this precise:

```
hue family    = namespace / entropy type
saturation    = refinement level (layer depth)
brightness    = convergence state (compact=dim, expanded=bright, threshold=peak)
alpha         = reference count (orphaned entries fade, live entries stay bright)
```

a module with refcount approaching zero will visibly fade in the iris.
a module reaching threshold will pulse brightly at its ring position.
the color proportion across the full wheel = the entropy proportion in the system.
color imbalance = immediately visible = investigation prompt.
