## Vision Through Waves

### Seeing the Network See Itself

```

Wave 0 (Local vision):
  "What do I see from my leaf node?"
  → My local checksums
  → My branch's hot content
  → Network canonical versions
  → Limited but immediate

Wave 1 (Branch vision):
  "What does my community see?"
  → Aggregated branch statistics
  → Regional patterns
  → What my neighbors reference
  → Broader but still local

Wave 2 (Network vision):
  "What does the whole network see?"
  → Global synthesis (delayed)
  → Canonical content
  → Universal patterns
  → Comprehensive but not real-time

The complete picture emerges from all waves together.
No single wave shows everything.
All waves together include everything.
```

### Discoverability Matching Potential

```
The goal: Match discoverability to relevance/importance

Relevance = f(reference_count, recency, semantic_fit)
Importance = f(network_health, community_value, longevity)
Potential = f(quality, uniqueness, timeliness)

Wave mechanics ensure:
  • High reference_count → High discoverability
    (Wave 1: branch replication)
    (Wave 2: global canonicalization)
    
  • Sudden spikes → Rapid response
    (Wave 0: local detection)
    (Wave 1: immediate aggregation)
    
  • Semantic fit → Proximity discovery
    (Similar checksums cluster)
    (Related content co-locates)
    
  • Quality → Persistence
    (Good content stays referenced)
    (Waves keep including it)
    
Result: Discoverability ∝ Actual Value
       (Not just popularity)
       (Not just age)
       (Not just advertising)
```

## The Discovery Cascade

### How Content Rises

```
Stage 1: Inclusion
  CHKSM_X enters network
  → Stored in dedup tree
  → Participates in Wave 0
  → Reference count = 0 (but known)

Stage 2: First Discovery
  One user finds CHKSM_X
  → Reference count = 1
  → Wave 0 carries to branch
  → Wave 1 notes existence

Stage 3: Sharing
  User shares with friends
  → Reference count = 5
  → Wave 1: "emerging content"
  → Limited branch replication

Stage 4: Virality (possible)
  Content resonates
  → Reference count spikes to 500
  → Wave 1: "hot content"
  → Wave 2: "canonical candidate"
  → Broad replication
  → High discoverability

Stage 5: Settling (or fading)
  If sustained value:
    → Remains canonical
    → Continues high discoverability
  
  If temporary spike:
    → Reference count stabilizes
    → Replication adjusts
    → Finds natural level

The wave ensures accurate positioning.
```
