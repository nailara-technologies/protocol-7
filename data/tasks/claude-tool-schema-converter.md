## claude code tool calls as an edge format : an additional, compatible path

owner idea 2026-11-25. idea only, nothing built.

- a model trained on claude code's tool calls [ Bash, Read, Write, Edit,
  Grep, Glob, .. ] could drive p7 tools through a converter at the edge :
  Read -> read_file, Grep -> search_code, Edit -> edit_file \
  replace_in_file, .. [ native is the hub : the foreign form stays outside,
  inward exact ]
- additional, never instead : the native p7 commands stay the primary
  interface. they are optimised continuously [ pagination, ncode, the tree
  tools ] -- a true claude model would likely come to prefer them, the
  converter keeps the door open for the ones trained on the classic set
- the reference for names and argument shapes : our own transcripts
  [ ~/.claude/projects/*/*.jsonl -- p7-session-normalize and
  claude.context.usage already read them at the edge ], not secondhand lists ;
  a small extraction gives the catalogue [ names, argument keys and types,
  use counts ]
- the mapping is also a map of gaps : a classic call with no native
  counterpart names a native command worth adding
