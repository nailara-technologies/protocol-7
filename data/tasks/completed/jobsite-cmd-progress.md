## task: jobsite.progress command — ASCII progress bar

### output format

mirrors the `bin/ptd` `show_progress` function exactly:

```
:::[:::::::::    ]::[ assessed: 702  review: 145  new: 16 ]:.
```

left bracket: 13-char bar filled with `:` proportional to assessed/total.
right bracket: contextual stats string (see below).
trailing `:.` and newline.

### color codes (copy exactly from bin/ptd)

```perl
my $reset      = "\e[0m";
my $blacklight  = "\e[38;2;68;39;172m";
my $nailara_bg  = "\e[48;2;9;5;42m";
my $TRUE_color  = "\e[38;2;6;71;195m";
```

rendered string:

```perl
sprintf(
    "${blacklight}:::[$nailara_bg$TRUE_color%-13s"
        . "$reset$blacklight]::"
        . "[$nailara_bg$TRUE_color %-${rw}s "
        . "$reset$blacklight]:.$reset\n",
    $bar, $right
)
```

where `$rw` = length of `$right` (no padding needed — just use the string).

### progress calculation

```perl
my $total    = scalar keys %{ <jobsite.tasks> // {} };
my $new_c    = scalar grep { ( $_->{'status'} // '' ) eq 'new'      }
                   values %{ <jobsite.tasks> // {} };
my $assessed = scalar grep { ( $_->{'status'} // '' ) eq 'assessed' }
                   values %{ <jobsite.tasks> // {} };
my $review   = scalar grep { ( $_->{'status'} // '' ) eq 'review'   }
                   values %{ <jobsite.tasks> // {} };
my $pending  = <jobsite.pending_count> // 0;

my $done     = $total - $new_c;
my $chars_max = 13;
my $filled    = $total > 0 ? int( $chars_max * $done / $total ) : 0;
my $bar       = ':' x $filled;
```

### right bracket content

```perl
my $cycle = <jobsite.cycle> // 'idle';

my $right = do {
    if ( $cycle eq 'assessing' and $pending > 0 ) {
        "assessing: $pending remaining";
    } elsif ( $cycle eq 'scanning' ) {
        'scanning sites..';
    } else {
        "assessed: $assessed  review: $review  new: $new_c";
    }
};
```

### reply mode

return a `true` mode reply with the formatted string as `data`:

```perl
return {
    'mode' => 'true',
    'data' => $output_str,
};
```


no change needed. check the existing access lines first and only add if the
command would not already be covered.
