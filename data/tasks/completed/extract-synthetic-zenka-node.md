## task: extract inline sub from plugin.web.space.orbital.json.context

### problem

`plugin.web.space.orbital.json.context` has an inline `sub _synthetic_zenka_node`
at line 34. because the module is loaded by both the "reload source" and "reload
plugins" stages of `base.cmd.reload`, perl sees the sub defined twice and emits:

    Subroutine _synthetic_zenka_node redefined at
    .. plugin.web.space.orbital.json.context line 34.

this warning fires twice per reload, cluttering the log and blocking a clean
reload result.

### fix required

extract the inline sub into a proper P7 module file so it is registered in
`%code` and called via `<[...]>` syntax instead.

```
## [:< ##

# name  = plugin.web.space.orbital.synthetic-zenka-node
# descr = build synthetic orbital node from zenka identity (ctx + name)
#         deterministic hash → base32r addr → orbital angles

my $ctx  = shift // '';
my $name = shift // '';

## deterministic hash from context + name ##
my $hash_input = sprintf( 'zenka:%s:%s', $ctx, $name );
my $hash_hex   = eval {
    <[base.perlmod.autoload]>->('Digest::SHA');
    Digest::SHA::sha256_hex($hash_input);
} // do {
    my $sum = 0;
    $sum = ( $sum * 31 + ord($_) ) & 0xFFFFFFFF for split //, $hash_input;
    sprintf( '%08X%08X', $sum, $sum ^ 0xAAAAAAAA );
};
my @bytes = map { hex($_) } unpack( '(a2)*', substr( $hash_hex, 0, 8 ) );

## encode first 4 bytes as base32r addr ##
<[base.perlmod.autoload]>->('Crypt::Misc');
my $packed = pack( 'C4',
    $bytes[0] // 0,
    $bytes[1] // 0,
    $bytes[2] // 0,
    $bytes[3] // 0 );
my $addr_b32 = Crypt::Misc::encode_b32r($packed);
$addr_b32 =~ s|=+$||;
$addr_b32 =~ tr|a-z|A-Z|;
$addr_b32 = substr( $addr_b32, 0, 16 );

return {
    qw| p7ref    | => sprintf( 'NODE:%s:%s', $name, $addr_b32 ),
    qw| hostname | => $name,
    qw| theta    | => ( ( $bytes[0] // 0 ) / 255 ) * 360,
    qw| phi      | => ( ( $bytes[1] // 0 ) / 255 ) * 360,
    qw| psi      | => ( ( $bytes[2] // 0 ) / 255 ) * 360,
    qw| omega    | => ( ( $bytes[3] // 0 ) / 255 ) * 360,
    qw| age      | => 0,
};
```

**do not add** the `#,,.,,,...` stub footer — leave the file clean for the
signing system (`bin/Protocol-7 sourcecode update-signatures` adds the real footer).

## signatures note
