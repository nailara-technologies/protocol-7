concept

omega is not the end. it was always the gate.
the forward signal arrives at omega, reflects as gamma, and returns enriched.
the standing wave between alpha and omega IS the resonant system —
two waves flowing in opposite directions, weaving together, alive.

full specification

layout : full-page horizontal canvas, full viewport width/height
         alpha at left edge · omega at right edge
         center horizontal axis — the zero line, very dim (1px, 20% opacity)

forward wave : amber bezier, slightly above center axis
               flows left→right continuously (animation)
               stroke: #F39C12, glow rgba(243,156,18,0.4), 2px

gamma return (γ) : violet bezier, slightly below center axis
                   flows right→left simultaneously (opposite direction)
                   stroke: #8A2BE2, glow rgba(138,43,226,0.4), 2px

superposition : luminous neutral curve between the two waves
                slightly thicker (4px vs 2px)
                stroke: #C8A96E (warm-neutral blend), 60% opacity

omega gate (Ω) : bright vertical line at right edge, white-gold #FFE5A0
                U-curve where forward meets gamma: the most visually striking element
                U-curve glows brighter than anything else in the scene
                pulse: ±5% brightness, 2s cycle (the gate breathes)

interference : right 15% of canvas only
               alternating bright/dim vertical bands (harmonic memory omega holds)
               resonant bands: gold 60% opacity · transform bands: near-black 80%
               subtle shimmer animation — visible but not competing with U-curve

labels : "α" left edge, warm amber · "Ω" right edge, white-gold
          "γ" along the return wave, small, cool violet, italic
          all small monospace, no crowding

tweaks panel : use tweaks-panel.jsx from iris.v7.ax/vortex/
               controls: wave speed (0.5×–3×) · amplitude · interference intensity
               toggles: show/hide forward · gamma · superposition · labels

output files : standing-wave.jsx · index.html
               title: "omega gate · iris.v7.ax"
               reference palette from iris.v7.ax/vortex/iris.jsx

success test

the visual passes when :

someone sees the right edge and understands intuitively that it is not an endpoint — the forward wave does not stop, it turns and becomes the return. the U-curve makes this undeniable without any explanation needed.

the two colours (warm amber / cool violet) tell the story of the two directions without words. the system feels alive — breathing, resonating, not static.

the interference bands near Ω suggest memory — something accumulated, held, reflected back — without explaining what memory means here.
