<h1>Weather Information</h1>

<p>This page demonstrates inter-zenka communication through template tags. The weather widget below calls the <code>weather.widget</code> command, which formats weather data with psychedelic blacklight styling.</p>

<div class="info-box">
    <h3>Inter-Zenka Communication Pattern</h3>
    <p>Template tags like <code>&lt;[weather.widget]&gt;</code> are processed by the <strong>web zenka</strong>, which can communicate with other zenki (such as the <strong>weather zenka</strong>) via IPC to fetch real-time data.</p>

    <p>Architecture flow:</p>
    <ol>
        <li><strong>httpd zenka</strong> receives request for <code>/weather/</code></li>
        <li>Loads content from <code>/data/web-root/vhosts/default/04_weather/index.txt</code></li>
        <li>Offloads template processing to <strong>web zenka</strong> via IPC</li>
        <li><strong>web zenka</strong> encounters <code>&lt;[weather.widget]&gt;</code> tag</li>
        <li>Resolves to <code>weather.cmd.widget</code> module automatically</li>
        <li>Calls weather module, which can query <strong>weather zenka</strong> for data</li>
        <li>Returns formatted HTML with psychedelic styling</li>
        <li>Result wrapped in skin template and returned to client</li>
    </ol>
</div>

<h2>Live Weather Widget</h2>

<[weather.widget]>

<div class="tech-notes">
    <h3>Technical Implementation</h3>
    <ul>
        <li><strong>Recursive template parsing</strong> using <code>base.parser.pattern_split</code></li>
        <li><strong>Psychedelic CSS</strong> with dark blue (#000014) background, cyan (#22d3ee) and purple (#a78bfa) neon glows</li>
        <li><strong>Icon handling</strong> with alpha-transparent borders and drop-shadow filters</li>
        <li><strong>Animated effects</strong>: border-pulse, text-glow, icon-pulse animations</li>
        <li><strong>IPC communication</strong> via <code>base.protocol-7.command.send.local</code></li>
    </ul>

    <p>The widget currently displays example data. When the weather zenka is fully operational, it will fetch real-time data from the OpenWeatherMap API configured in <code>cfg/zenki/weather/zenka.v7</code>.</p>
</div>
