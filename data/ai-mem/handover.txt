### Key patterns learned this session
- P7 cmd modules: return { 'mode' => 'true'|'false'|'size', 'data' => ... } directly
- P7 reply handlers (route-send): get $call->{'mode'} as uppercase 'SIZE'/'TRUE'/'FALSE'
  → always use lc($mode) eq 'false' for error check
- SIZE reply data in route-send handler: $reply->{'data'} is a plain STRING (not sref)
  (sref only in stream path — handler.command line 741)
- Multiline call_args->{'args'}: must be B32-encoded or cube parses lines as protocol cmds
- base.X prefix exists only on disk; called as X in code
- $ARG = $_ (English.pm); $ARG[0] = $_[0] = first subroutine argument
- file.zenka_dir.load returns undef if file absent, sref otherwise; use :raw encoding
- file.read returns content string directly; file.slurp returns scalar ref
- task.show output: 'description : value' (space before :); task content may embed
  'description:value' (no space) → parser must require \s+ before :
- models.handler.task-poll-step: reads task.show SIZE reply, parses header until 'result :'
  then routes by :local: prefix → coding.ask-reply; :simple: → no_tools=1,max_rounds=1
- ncode -ai-friendly -confirm replace src 'pattern' 'replacement' — bulk safe replace
- p7c job-site-scan.set key value  (via devmod — much better than eval-code)
- p7c job-site-scan.del key        (delete namespace key)
