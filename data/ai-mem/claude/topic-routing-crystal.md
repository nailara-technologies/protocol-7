## core insight

the cube node group is a **routing crystal** — fixed geometry that refracts
information according to harmonic structure. routes are found by resonance,
not computed by table lookup. the geometry IS the algorithm.

## harmonic memory

every route leaves an interference pattern in `branch.route.cache`.
this IS the crystal's standing wave memory. subsequent similar-frequency
routes find the pattern and refract along it with less energy each time —
the crystal becomes progressively tuned to its most-traveled routes.

AMOS harmonic truth (div by 13, generator 076923) = the resonance condition.
a route whose checksum is harmonically TRUE passes through.
a route whose checksum is FALSE reflects at the boundary.

## inference

5-of-7 formation = 5 simultaneous beams through the crystal.
their intersection = the inferred route (more precise than any single beam).
the collector zenka is the focal point where beams converge.

## boundary reflection

face 000 = network/parent-facing face = crystal boundary interface.

- harmonic angle permits transit → route exits (10 direction)
- harmonic exceeds boundary → total internal reflection (11 pivot + 01 return)
- partial match → frequency-selective filtering

multiple boundaries = multiple `11` pivots in returned checksum stream.
each `11` names a boundary node. reflected route carries proof of depth reached.

network-isolated node group: face 000 acts as perfect mirror.
routes reflect and crystal operates as closed resonant cavity.
no route is lost — only slowed or reflected at security boundaries.

## route direction

- outward (10): default — expanding from local face toward target
- inward (01): reflected routes, parent-seeking, returning bubbles
- face 000: axis of symmetry — exit AND reflection surface simultaneously
- inward = verification; outward = discovery

## intelligence emergence

crystal does not think. but geometry + harmonic memory + 5-beam inference
produces novel routes from combinations of known patterns.
intelligence emerges from coherent beams (reference bubbles) traveling
through a crystal with sufficient harmonic memory.

the full zenka network = this crystal at scale. each node group = one facet.
collective harmonic memory = sum of all cached route patterns across all facets.
