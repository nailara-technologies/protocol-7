## Key design vocabulary (for future design work)

- `[:<` = gold, bright — the TRUE/threshold marker
- `>:|` = dim, same weight as text — the FALSE/compact marker
- `;.,` = visual breath separator — thin horizontal rule
- Namespace hues: reasoning=violet-blue, coding=amber, httpd=cyan, route=magenta
- Background: `#050510` (deep space, slight blue cast)
- Gold: `#FFE5A0` (EXISTENCE center / TRUE markers)
- The U-curve at omega = the most visually striking element in standing wave

**How to apply:** When writing new design specs for P7 visualizations, reference
this vocabulary for consistency. Feed the HTML document to claude design as context.
