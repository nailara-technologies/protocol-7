owner 2026-11-28 : "yes, you can always push them, no problem" -- committed commits on `base`
go to the hub [ `git push hub base` ] without asking each time.

**Why:** the hub should stay current ; asking per push only adds a round trip.
**How to apply:** push after commits as part of the normal flow. deploying to the servers
[ pull-git, restarts ] is covered separately by [[remote-root-ssh-restart-authorized]] ;
force pushes and history rewrites still need the owner.
