stated by the user 2026-10-16 :
- claude **fast mode** [ cli \ cloud sessions : `/fast`, a toggle ] draws on
  the normal plan usage limits, like regular sessions.
- only the **Fable** model is billed separately, from usage credits -- never
  pick it for routine work.
- the user keeps cloud sessions at effort **low** on purpose to save the
  promotional credits ; the cloud dispatch tool sends no effort \ model \
  fast unless asked.

**How to apply:** fast mode [ and kimi's `k2.7-fast` : ~6x speed, 3x quota ]
is the tool for the end of a window -- tokens a closing 5 h \ 7 d window
would lose anyway buy speed instead. read the remaining time from
`usage.status` [ per window ] before suggesting it ; never as a default.
