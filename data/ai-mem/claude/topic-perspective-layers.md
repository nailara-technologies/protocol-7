## core insight

desktop = data space arrangement + UI abstraction intent.
no layout engine — branch namespace tree IS the layout.
visual proximity = data proximity. screen depth = harmonic consensus.
centered on screen = current darksun.

## layers

each layer = spawned on-demand zenka + view spec resource on branch node.
all structurally identical (each IS observer-centric, each IS 0 to itself).
differentiation = geometric offset + orientation + focal length + scope only.

layer 0: personal darksun (offset=0)
layer 1: local neighborhood (offset toward nearby high-ref)
layer 2: network reference center (offset toward aggregate attention) → recursive
layer N: task context, tool, ambient...

parallax between layers = UI depth cue. consensus across layers = darksun.

## UI as optimization

contextualized emerging UI = minimum representation preserving relevant structure.
- summarization: reference count → visual prominence (size/depth/brightness)
- perspective tree: branch tree IS the UI tree; depth = distance from darksun
- bandwidth reduction: only inner shells rendered; outer shells implied
- focal length = tunable bandwidth: narrow=less, wide=more, omni=all

## nested resolution = data derivation route

layer N resolves within context of layer N-1 → ... → layer 0 → branch.node.path
the layer stack IS the derivation path. implicit, auto-computed, no explicit spec.

## changing the UI

zoom in = increase focal length
zoom out = decrease focal length (toward omni)
new workspace = spawn perspective layer
context switch = change primary observer layer
all UI changes = view spec parameter changes only; data space unchanged
