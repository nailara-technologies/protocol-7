`p7c usage.status` [ usage zenka ] prints claude and kimi usage : 7d and 5h percent plus the
time left until each window resets.

2026-11-24 : `p7c usage.plan [ claude | kimi ]` is the pacing view [ owner : it "gives you a
feeling for the values exactly as it should be" ] -- 7d then 5h with bars, 5h windows left before
the 7d reset, share per window, the pace in this window on both scales [ slow down \ speed up
factor ], a share-used bar. check it before deciding how much to dispatch in a window.

owner 2026-11-23 : query it myself to decide what to still dispatch, and set a background timer
for the 5h reset so queued work goes out right when the window opens [ see
[[token-budget-pacing-early-week]] : after a one-time reset the week budget is meant to be used ].
