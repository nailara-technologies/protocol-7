## The network IS the computer (May 2026)

geometry from which any and everything can be instantiated — because it is
always in-between, always complete, always computing by existing.

## Base32 / 15-bit / 32-bit closure

- 15 bits = 3 × 5 bits = **3 Base32 characters** — arc segment address is natively
  Base32, no conversion needed
- 26 arc segments = **A-Z** — the alphabetic Base32 characters claim the geometry
- Base32 remainder: 2-7 (6 digits) completes the decimal group — not arbitrary,
  exactly what's needed to close the set into a decimal-compatible structure
- 0 and 1 excluded from Base32 = harmonic boundary markers, the even/odd ramp
  primitives reserved because they carry a more fundamental function than arc labels
- **32 symbols address a bit position in 32-bit space** — the loop closes:
  every Base32 character is simultaneously a symbol, an arc segment, a bit position
  in a 32-bit register, and a shift operation
- the network is a self-similar bit-shift register complex that computes by existing
