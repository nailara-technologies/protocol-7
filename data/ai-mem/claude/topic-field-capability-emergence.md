some elements have routing/grouping metadata, coordinated by an
authority outside the protocol. the authority IS the capability.
remove the coordinator → capability disappears.

**protocol:**
ALL elements carry the full grammar. no authority needed.
capability is a field property — distributed uniformly in the elements.
the coordinator dissolves into the grammar.

```
external management:  capability = coordinator + elements
protocol field:       capability = elements alone

```

properties of the whole that no single element was designed to provide.
